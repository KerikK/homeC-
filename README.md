 Консольна гра "Поле чудес" (C++)

Правила гри
1. При запуску обирається випадкове питання та зашифроване слово.
2. Гравець може:
Вгадувати окремі літери.
Спробувати назвати слово повністю.
Скористатися **підказкою** (відкриває одну літеру).
3. Кожна використана підказка додає +2 секунди до підсумкового часу.

Особливості реалізації
Кольоровий вивід та текстове оформлення в консолі.
Імітація обертання барабана (затримка та анімація).
Підтримка підказок та штрафного часу.
